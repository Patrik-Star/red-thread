# Overview

**Red Thread** — a phone-run outdoor mystery game for groups of friends: solve a real Auckland crime (murder or theft) on foot, each player with different clues on their own phone. Auckland first, then the rest of NZ. Domain: redthread.co.nz.

- **Stage:** idea · **Founder:** Patrik (solo side project) · **Started:** 2026-10-26
- **Verdict so far:** promising, not yet validated. The number to validate is **paid games per month**.
- **Positioning:** outdoor escape room, not a walking tour. Target: Auckland friend groups (22–40) who've done the escape rooms.
- **Price (hypothesis):** NZ\$89 per group (3–6) · NZ\$49 for 2.
