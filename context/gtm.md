# Go-to-market strategy

2026-10-26 · stage: idea → **validation-oriented GTM**: small capped bets that test demand. No customer interviews yet, so positioning and messaging are hypotheses.

> **Promise:** An escape room the size of Auckland. **Price:** NZ\$89/group (3–6) · NZ\$49 for 2. **Channels:** Google Search ads + Bookme, with free community playtests as the experiment. **Goal:** 5 paid groups and 10 reviews in the first 30 days (Feb 2027); ~20 paid plays/month by Oct 2027.

## 1. Positioning

**Competitive alternatives:** (1) indoor escape rooms — 7+ Auckland operators at \$31–45 pp; (2) the default outing (drinks, dinner, bowling, quiz) — biggest competitor overall; (3) outdoor phone games (Seekers Code, Questo, City Game) — cheap, easy, tourists/families; (4) home murder-mystery kits.

| Unique attribute | Escape room? | Seekers Code/Questo? |
| --- | --- | --- |
| Hard, real deduction (who, how, why) | puzzles, not deduction | no — easy riddles |
| Own role + private clues per phone | no | no |
| Outdoors, story written for real Auckland places | no | generic scripts |
| Any day, any time, no capacity limit | no | yes |

**Value:** the "we cracked it" high; nobody stands around watching; fits around the day; ~half an escape room per person for ~twice the time.

**Who cares most:** Auckland friend groups 22–40 who've done a few escape rooms. Trigger: "we've done them all, what's next?" or an occasion (birthday, visitors, double date). The organiser books and pays.

**Category:** "outdoor escape room". Avoid "murder mystery walk" / "treasure hunt" (cheap, easy box).

> For **Auckland friend groups who love escape rooms and have run out of new ones**, **Red Thread** is an **outdoor escape room** that turns the city into the puzzle: a real crime to crack in under 2 hours, with every player holding different clues on their own phone. Unlike walking mystery trails, it's genuinely hard, and unlike indoor escape rooms, you play any day, at your own pace, for about half the price per person.

## 2. Messaging house

**Roof:** *An escape room the size of Auckland.*

| Pillar | Proof |
| --- | --- |
| **Actually hard** | Ends in real deduction; difficulty rating; finish rate and hint use from playtests (TBD) |
| **Everyone plays** | Each player gets a role and private clues; interrogations only one person hears |
| **Your city, your time** | Real Auckland places; any day; ~2 h; digital clues that don't go missing |

| Objection | Answer |
| --- | --- |
| "Too hard, we'll get stuck" | Choose-your-help hint system; you can't fail to finish; publish finish rate |
| "Seekers Code is cheaper" | It's a nice family walk. This is for groups who'd otherwise book an escape room, at ~half the price pp |
| "What if it rains?" | Ticket valid 12 months |
| "Murder isn't for everyone" | Thefts and disappearances too |
| "Phone will die / bad signal" | Works offline; rejoin from another phone |
| "How far do we walk?" | Stated per route, near cafés and bars |

**Assets:** homepage hero = roof + "Book for your group, play any day" · Google ads = "Outdoor escape room in Auckland: done all the escape rooms? Try the city" · Bookme = roof + difficulty + "each player gets different clues" + reviews · Reddit/Meetup = honest playtest ask.

**Words to avoid:** "Clue"/"Cluedo" (trademark), "sleuth", "AI-powered", "immersive experience", "treasure hunt", "for all ages". **Customer words** (from competitor reviews): "too easy", "not challenging", "we wanted a real investigation".

## 3. Channels

| Channel | Score /20 | Role |
| --- | --- | --- |
| Google Search ads | 17 | **Core 1** |
| Communities (Reddit, Meetup, uni clubs) | 16 | **Experiment** (playtests) |
| Referral / word of mouth | 16 | built into product |
| SEO / content | 15 | foundation only |
| Bookme (+ white-labels) | 14 | **Core 2** |
| Local media | 14 | launch spike |
| Fever, partnerships | 12 | later |
| Paid social | 11 | no |

CAC ceiling ≈ first-sale contribution ≈ \$70.

- **Google Search ads** — 2 ad groups (escape-room keywords; things-to-do/birthday). Cap \$100/mo. Success: ≥ 3 bookings from first \$200. Kill: < 1 booking per \$150 after \$300. Get volumes/CPC from Keyword Planner first.
- **Bookme** — list as "Outdoor Escape Room — Auckland CBD". Commission unknown: ask before listing. Success: ≥ 3 bookings in 30 days, ≥ 4.5★. Kill: 0 bookings in 60 days.
- **Community playtests** — Jan 2027, r/auckland + 2–3 Meetup groups, 5 free groups for feedback + review + "bring another group" code. Success: 5 groups, ≥ 8 reviews, ≥ 2 paid referrals in 60 days. Kill: < 3 sign-ups from 3 posts.
- **SEO** — one landing page per game + "Escape rooms in Auckland: the outdoor option". Target category phrases, not the brand name.

## 4. Pricing

- Anchor between escape rooms (\$124–180 for 4) and outdoor trails (\$25–53/group). Price **per group**.
- **Group (3–6): NZ\$89** · **Duo: NZ\$49** · average ≈ \$80 (matches business model base).
- Not cheaper: price signals "harder than a trail".
- Launch: no Bookme discount; "bring another group" code for playtesters; \$10-off code on own site for 30 days (channel attribution).
- Test: Van Westendorp questions at the end of interviews. If most "getting expensive" < \$89, start at \$79.
- Later: gift vouchers, team-building, multi-game bundle.

## 5. Launch plan (soft launch, early Feb 2027)

**Goal:** 5 paid groups in 30 days. Secondary: 10+ reviews, 100 email subscribers, finish rate and rating from every group.
