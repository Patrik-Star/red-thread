# Colours

A live reference for every colour token: swatches by role, each approved pairing rendered with its contrast calculated live in the current theme, the colours used on a real game screen, and the pairings not to use. The full tables are in the brand book's Colour section.

- Switch the theme to check Night and Paper. Values and ratios update to match.
- Badges: **Text** (4.5:1+, any size), **Large / graphic** (3:1+: text 24px+, thread lines, pins, borders, focus rings), **Decorative** (under 3:1, no meaning).
- This is documentation, not a component to ship.
