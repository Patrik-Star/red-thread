# 🧵 Red Thread

An escape room the size of Auckland. A phone-run outdoor mystery for 3–6 friends: solve a real Auckland crime on foot, every player holding different clues on their own phone.

This repo holds all project context (business, go-to-market, game design, cases, playtests, decisions) and the Claude skills used to work on it. Start with [`CLAUDE.md`](CLAUDE.md) and [`context/overview.md`](context/overview.md).

```
context/      business model, GTM, game-design rules, overview
cases/        one folder per case (case.md + solution.md)
playtests/    one file per playtest session
decisions/    append-only decision log
templates/    case and playtest templates
.claude/      project skills for Claude
```
