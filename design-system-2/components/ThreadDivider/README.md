# ThreadDivider

The red thread as a section break: a `thread-width` line in `thread` with a knot in the middle, or a chapter label in mono.

- Use it between chapters of a case or major sections of a page, and no more than once per screen. It *is* the screen's thread.
- Label style: "Chapter II · The Ferry Building".
- Don't use it as a list separator. Use `line` hairlines for that.
- Consumer provides: an optional `label`.
