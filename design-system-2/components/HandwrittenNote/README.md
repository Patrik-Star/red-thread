# HandwrittenNote

A note written by someone in the story, on a page torn from a ruled notebook (`paper="plain"` for a scrap with no lines).

- `lines`: an array, one string per written line (or pass children). `signed`: an initial or name, set right.
- Set in `hand` (Caveat) at 24px. Never smaller than 22px, and never more than about 30 words: handwriting is slow to read on a phone at night.
- Handwriting is evidence only. The game never writes to the team by hand.
- Wrap in `Evidence`.
