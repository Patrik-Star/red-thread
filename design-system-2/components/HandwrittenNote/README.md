# HandwrittenNote

A note written by someone in the story, on a page torn from a ruled notebook (`paper="plain"` for a scrap with no lines).

- `lines`: an array, one string per written line (or pass children). `signed`: an initial or name, set right.
- Written in `evidence-pen` (blue-black ballpoint), with each line drifting slightly off the ruling the way a real hand does.
- Set in `hand` (Caveat) at 24px. For a note a puzzle depends on, have a person write it and scan it at 2x. A real hand beats any font, and give the scan the same words as `lines` for screen readers. Never smaller than 22px, and never more than about 30 words: handwriting is slow to read on a phone at night.
- Handwriting is evidence only. The game never writes to the team by hand.
- Wrap in `Evidence`.
