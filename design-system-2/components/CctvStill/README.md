# CctvStill

A security-camera still printed as a photo: square, a white print border, image forced to greyscale, with camera, place, date and time burned into the frame.

- `src`, `alt` (required with `src`), `camera`, `place`, `date`, `timestamp`, `slot`.
- With no `src` it shows a dark frame reading "No signal", which is safe to ship. Pass `slot` ("Photo to come: Chancery Square, facing Queen St") to mark a production placeholder with a dashed inner frame. A `slot` must never reach players: replace it with a photo shot on site.
- Imagery follows the brand: Auckland places at night, people as backs or silhouettes, never victims.
- The burned-in timestamp is often the evidence. Make sure it agrees (or deliberately disagrees) with the case timeline.
- Wrap in `Evidence`.
